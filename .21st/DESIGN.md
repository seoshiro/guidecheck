# GuideCheck workspace design

Use a quiet technical review workspace: forest rail, warm neutral canvas, clear editorial typography, two contextual diff panels, and restrained amber attention states. Keep guide ownership, selected versions, evidence context, and original timestamps visible. The main workflow remains compare, review, correct, and export; history is one alternate view of the same guide.

Use existing local system fonts and Lucide icons. No gradients, cloud font requests, animations beyond optional loading indicators, or decorative stock images. Synthetic screenshots are original fixtures and labelled as such. Ensure visible keyboard focus, native modal focus containment and Escape, semantic form labels, responsive stacked diff panels, search/filter empty states, explicit validation errors, and reduced-motion support.
